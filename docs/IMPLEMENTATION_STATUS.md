## 动画与世界观表达

- 交互星图：22 个途径节点、九组高序列关系、选中态与同组连线，配合筛选和来源说明。
- 升格页面：序列 9 → 0 的阶梯、同心轨道、光轴与层级变化；内容随所选序列切换。
- 阅读体验：灰雾、细纹、渐入和微光；系统或站内减弱动画设置可关闭流动效果。
- 首页组织：探索途径、发现自己与继续探索。第三阶段互动故事未开放，不提供虚假入口。
- 徽记、色彩和星图为本站艺术设计；分组表示高序列关联，不表示任意序列都能自由转途径。
- 二十二套独立艺术徽记按途径主题设计，星图、详情、比较、身份展示与下载卡片共用同一套矢量；没有把这些图形称为原著官方标志。
- 新增选中星点的单次微光、徽记线条显现和升格扩散环；修正旋转光环与升格缩放互相覆盖的问题。减弱动画时新增效果同样关闭。

## 验收时可直接操作

1. 在星图选择愚者，查看门与错误的同组关联；用方向键切换星图节点。
2. 打开途径详情，逐阶点击“向上探索”，观察序列内容和升格视觉。
3. 确认初访无进度弹窗，序列 0 可直接查看；星图关系、比较内容和搜索结果无需额外确认。动画设置只包含减弱动画选项。
4. 做完评估，查看主要与次要倾向、答案解释；修改昵称并下载身份卡，再刷新查看历史。
5. 搜索“5”，查看结果依据、来源与覆盖限制；收藏后到档案查看。
6. 确认档案页只显示本机保存说明，搜索无 AI 开关，页脚无通信与反馈入口；直接访问旧链接会跳回可用页面。
