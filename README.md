# 灰雾之上 · LOTM.space

《诡秘之主》非官方世界观探索站。React + TypeScript + Vite，支持中文和英文。

## 本地运行

```powershell
npm ci
npm run dev
```

打开本机 3000 端口。当前为纯浏览器版本，无需登录或后台配置；可以直接探索、评估、保存本机身份及收藏。

```powershell
npm run check
npm test
npm run build
npm run report
```

## 当前功能

- 二十二条途径的交互星图、独立艺术徽记、同组关联、九到零的序列阶梯与升格视觉。
- 途径详情、2—3 条比较、来源说明与减弱动画；全部序列、权柄关联和章节内容直接展示。
- 八个情境的娱乐评估，主要和次要倾向、匹配规则解释、固定版本的结果快照。
- 自选身份、昵称与徽记，22 条途径各自的叙事插画、1200×2000 PNG 卡片和通用途径分享链接。
- 浏览器本地档案、历史、收藏、备份导出和继续探索。
- 章节号与标题检索、有限情节索引，全部在浏览器执行。

按用户要求，暂时屏蔽 Google 登录、跨设备同步、AI 关键词辅助、同人通信、在线反馈与事件统计。旧入口会跳转到可用页面，API 返回 `404 disabled`；即使已有环境变量也不会启用这些服务。相关代码保留，后续恢复需同时调整页面入口与 `src/config/features.ts`，再按 [云端配置说明](docs/CLOUD_SETUP.md) 联调。已有浏览器档案不会被删除。

## 资料范围

数据包含 22 条途径和 220 个序列名称。目前 172 项能力摘要对照了所列参考，48 项细节仍标注待核对；晋升只收录少量已找到依据的要点，不是完整模拟器或配方库。来源按名称、能力、晋升及扮演分别标注，含官方英文原章、官方设定入口和二手索引，没有宣称完成全书逐章认证。

章节索引含 42 个已核对章号与标题，其中 12 章提供核对过的简短摘要；其余条目仅检索标题与章号。中文章节标题是本站译名。完整范围见 [途径核验记录](docs/CANON_AUDIT.md) 和 [章节纠错记录](docs/CHAPTER_AUDIT.md)。

[功能清单](docs/FEATURE_BACKLOG.md) 保留阶段范围，[实施验收记录](docs/IMPLEMENTATION_STATUS.md) 记录实际证据与剩余事项，[逐序列核验表](docs/CONTENT_REVIEW.md) 列出全部 220 个序列的内容依据及待确认项。第三阶段的故事、阿蒙事件及成长系统尚未开放。

本项目为同人创作，非官方出品。网站艺术徽记与动画不代表原著规定的图案。AI 输出不进入设定资料库。

## 身份卡视觉

身份卡采用维多利亚叙事插画与旧版画质感，每条途径分别设计场景、材质和边饰。插画由内置 imagegen 辅助原创生成，属于本站同人美术，不是官方徽记或原著规定图案。页面预览与 PNG 下载共用绘制逻辑，昵称与序列文字实时生成；高清导出为 1200×2000。

[视觉与验收说明](docs/IDENTITY_CARD_REDESIGN.md) 记录参考、素材位置和检查范围。
