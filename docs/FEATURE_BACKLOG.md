## 产品目标与范围

**当前开放范围（2026-10-23 调整）：** 无需后台和登录的浏览器版本。保留星图、详情、比较、评估、身份卡、本机档案与收藏、普通搜索。F08 的 AI 部分、F10/F11 同人通信与额度、F19/F20 云端部分、F29 统计及 F30 在线反馈均暂时关闭；相关实现保留供后续恢复。下表保留完整规划及历史实现状态，不能视为这些功能当前开放。

建设忠于原著、可以探索和参与的《诡秘之主》世界观体验站。核心流程为：了解途径 → 完成评估 → 保存身份 → 参与故事 → 留下探索记录。

- 资料以原著 22 条途径为边界；名称、能力、晋升条件须核对来源。原著未明确的内容标记“未明确”，不补造设定。
- 原著资料、娱乐评估和原创同人故事采用明确的内容标识；AI 输出不能直接成为原著资料。
- 第一阶段服务阅读与探索，第二阶段建立身份档案，第三阶段用一个完整短篇验证互动需求。
- 下表“现有功能核对”保留下载时的仓库基线。当前已安装依赖、完成本地实施与浏览器验收；实际交付和限制见 [实施验收记录](IMPLEMENTATION_STATUS.md)。云端配置按用户决定后续处理。
- 周次为相对推进顺序，正式排期需在设定整理和工作量评估后确定。
