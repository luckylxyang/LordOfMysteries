# 途径身份卡视觉更新

## 结果

已将现有身份卡替换为插画占主要篇幅、底部动态铭牌的收藏卡。22 条途径各自有完整的场景、边饰及材质，使用旧版画刻线、维多利亚城市与隐秘叙事统一美术语言。愚者、错误、黑暗三张延续用户确认的概念方向；其余途径按本地资料中的权能与意象分别设计。

- `public/art/identity/`：22 张经过 WebP 编码的原创插画，每张约 0.5—0.7 MB，页面仅加载当前途径；解码缓存最多保留四张。
- `src/data/identityArt.ts`：图像映射、文字明暗、双语视觉意象。
- `src/components/IdentityCard.tsx`：带可访问名称的实时预览、加载与失败重试。
- `src/utils/identityCard.ts`：预览与下载共用的 1200×2000 绘制器，处理双语标题、长昵称和两行摘要。
- `design/identity-preview-v2/production-prompts.json`：内置 imagegen 使用的完整提示词，按途径记录。

插画中的高位格意象代表整条途径的美术主题，不代表角色已获得相应能力；身份铭牌仍显示序列 9。昵称、途径名、序列及来源标注均由页面绘制，未烘焙进插画中。测评正文在工具区完整保留，卡面摘要过长时省略。分享链接仍不携带昵称或答题记录。可在结果页直接选择另一条途径查看通用身份卡；切换不修改已保存的身份。

## 参考与素材来源

参考动画海报的建筑、光影及尺度关系，和 Kiuyan Ran 本人作品集中的《宿命之环》封面的叙事与印刷质感。未将参考作品作为网站素材，也未声明复制某位画师的个人风格。当前插画通过内置 imagegen 辅助原创生成，属于非官方同人美术。
